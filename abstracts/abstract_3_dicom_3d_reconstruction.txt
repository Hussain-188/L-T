Title: MedVoxel — An Automated Pipeline for Patient-Specific 3D Anatomical Model Reconstruction and Interactive Visualization from DICOM Imaging Data

Abstract:

Clinical interpretation of computed tomography and magnetic resonance imaging studies still relies predominantly on sequential review of two-dimensional slices, a process that demands considerable spatial reasoning from the clinician and often obscures the true three-dimensional relationships between adjacent anatomical structures. This work introduces MedVoxel, an end-to-end computational pipeline that ingests standard DICOM image series, reconstructs a spatially faithful volumetric representation, segments individual anatomical regions using deep learning, generates publication-quality surface meshes, and presents the result through an interactive browser-based three-dimensional viewer — all without requiring proprietary software or manual landmarking.

The pipeline proceeds through five sequential stages. First, a DICOM ingestion module reads the image series, extracts acquisition metadata — slice thickness, spacing, patient orientation, and reconstruction parameters — and arranges the slices into a geometrically consistent volume, compensating for irregular spacing and orientation mismatches. Second, a preprocessing stage applies intensity normalization, noise reduction, and isotropic resampling to produce a uniform voxel grid suitable for automated analysis. Third, a pre-trained deep learning segmentation model built on the MONAI medical imaging framework delineates target anatomical structures — such as organs, vascular networks, or bony anatomy — generating labeled volumetric masks with per-voxel confidence estimates. Fourth, a mesh generation module applies the marching cubes algorithm followed by Laplacian smoothing and decimation to convert each segmented region into a watertight triangulated surface mesh that preserves clinically relevant geometric features while remaining lightweight enough for real-time rendering. Fifth, an interactive web-based viewer built on Three.js allows clinicians and researchers to rotate, slice, zoom, toggle individual structures, and measure distances directly within the browser.

Validation will be conducted against publicly available annotated DICOM datasets from the Cancer Imaging Archive, with accuracy reported using Dice similarity coefficients and Hausdorff distance metrics. MedVoxel aims to democratize patient-specific anatomical visualization for diagnostic review, surgical planning, and medical education.
